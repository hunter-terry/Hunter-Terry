## What I build

Python tools that follow the same rules every time:

- **Preview before action** — nothing changes on disk
  without showing you first
- **Never delete, never silently overwrite** — files
  get moved or numbered, not destroyed
- **Verify the output** — AI responses are checked
  against rules, not trusted blindly
- **Local-first** — pipelines run on-device via Ollama
  and faster-whisper; nothing sent to the cloud
